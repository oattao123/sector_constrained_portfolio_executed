## 4. วิธีการคัดเลือกสินทรัพย์ทั้ง 6 แบบ

Summary.ipynb ทดสอบ **6 วิธีคัดเลือกสินทรัพย์** ที่มีความซับซ้อนเพิ่มขึ้นตามลำดับ:

---

### วิธีที่ 1 — Diversification Score (Simple Returns)

**แนวคิด**: คัดสินทรัพย์ด้วย Sharpe Ratio จาก Simple Returns คูณกับ (1 - ค่าสหสัมพันธ์เฉลี่ย)

```
Diversification Score = Sharpe × (1 - Avg Correlation กับพอร์ตเดิม)
```

**ขั้นตอน**:
1. คำนวณ Sharpe Ratio จาก Simple Returns สำหรับ 571 สินทรัพย์
2. กรองเก็บเฉพาะที่ **Sharpe > 0.2** → ได้ **193 ตัว**
3. คำนวณ Diversification Score ของแต่ละตัว
4. คัดเลือก **Stratified Top 30** (มีตัวแทนจากทุกกลุ่มอุตสาหกรรม)

**ชื่อ**: `Diversification Selected`

---

### วิธีที่ 2 — Ledoit-Wolf + Diversification Score

**แนวคิด**: เปลี่ยนจาก Sample Covariance ธรรมดาเป็น **Ledoit-Wolf Shrinkage** เพื่อให้ได้ค่า Sharpe และ Correlation ที่เสถียรกว่า ประมวลผลบน **GPU (CUDA)**

**สูตร Shrinkage**:
```
Σ_LW = (1 - δ) × Σ_sample + δ × Σ_target
```
โดย `δ` คำนวณแบบ Dynamic ตามสูตร Analytical (b² / d²)

**ขั้นตอน**:
1. คำนวณ LW Sharpe สำหรับ 571 สินทรัพย์ด้วย GPU
2. กรองเก็บเฉพาะที่ **LW Sharpe > 0.2** → ได้ **187 ตัว**
3. คำนวณ LW Diversification Score
4. คัดเลือก Stratified Top 30

**ชื่อ**: `LW Diversification Selected`

---

### วิธีที่ 3 — HRP Clustering + Max Sharpe per Cluster

**แนวคิด**: ใช้ **Hierarchical Risk Parity (HRP)** จัดกลุ่มสินทรัพย์ด้วย Ward Linkage แล้วเลือก 1 ตัวแทนที่มี **Sharpe สูงสุด** จากแต่ละ Cluster

**Distance Matrix**: `D = √(0.5 × (1 - Correlation))` ตามทฤษฎี HRP

**ขั้นตอน**:
1. สร้าง LW Correlation Matrix บน GPU
2. คำนวณ Distance Matrix และทำ Ward Linkage
3. แบ่งเป็น **30 Clusters**
4. เลือกหุ้น Sharpe สูงสุด 1 ตัวต่อ Cluster → ได้ **30 ตัว**

**ชื่อ**: `LW Sharpe Cluster Selected`

---

### วิธีที่ 4 — HRP Clustering + Max Diversification Score per Cluster

**แนวคิด**: เหมือนวิธีที่ 3 แต่เปลี่ยนเกณฑ์คัดเลือกในแต่ละ Cluster จาก Sharpe เป็น **Diversification Score สูงสุด**

**ชื่อ**: `LW Div Cluster Selected`

---

### วิธีที่ 5 — 2D-ACO (Ant Colony Optimization อิสระ)

**แนวคิด**: ให้มดเรียนรู้ **Synergy ระหว่างคู่หุ้น** ผ่าน Pheromone Matrix 2 มิติ (N×N) โดยไม่ถูกจำกัดด้วย Cluster

**พารามิเตอร์**:
- จำนวนมด (`num_ants`): 500
- จำนวน Iterations: 1,000
- Alpha (น้ำหนัก Pheromone): 1.0
- Beta (น้ำหนัก Heuristic): 2.0
- Evaporation Rate: 0.1

**กลไก 2D Pheromone**:
```
ก้าวแรก: เลือกด้วย pheromones_start (1D)
ก้าวถัดไป: เลือกด้วย pheromones_2d[last_picked, :] (2D)
→ มดเรียนรู้ว่าหุ้นคู่ไหน "ทำงานร่วมกัน" ได้ดีที่สุด
```

Fitness = **True Sharpe Ratio** คำนวณจาก LW Covariance Matrix บน GPU

**ชื่อ**: `ACO Selected`

---

### วิธีที่ 6 — 2D-ACO + Cluster Constraint

**แนวคิด**: เหมือนวิธีที่ 5 แต่เพิ่ม **ข้อจำกัดว่าต้องเลือก 1 ตัวต่อ Cluster** เพื่อบังคับให้พอร์ตกระจายความเสี่ยงข้ามกลุ่มอย่างแท้จริง

มดเดินทีละ Cluster แทนที่จะเดินอิสระ ทำให้ Pheromone Matrix เรียนรู้ **"ความเข้ากันได้ข้าม Cluster"**

**ชื่อ**: `ACO Cluster Selected`

## 8. การทดสอบ Co-Evolutionary ACO+EBGWO

Cell 18 ของ Notebook ทดสอบแนวทางใหม่ที่ซับซ้อนขึ้น: **รวม ACO (คัดสินทรัพย์) กับ EBGWO (หาน้ำหนัก) ในลูปเดียวกัน** พร้อม Monte Carlo Bootstrapping และ Entropy Regularization

### 8.1 รายละเอียดอัลกอริทึม

```
CO-EVOLUTIONARY LOOP:
┌─────────────────────────────────────────────────────────┐
│ 1. ACO Phase: เลือกสินทรัพย์ target_assets ตัว         │
│    - ใช้ Pheromone × Heuristic เป็นความน่าจะเป็น        │
│    - บังคับให้มีอย่างน้อย 1 ตัวต่อ Sector              │
│                                                         │
│ 2. EBGWO Phase: หาน้ำหนักที่เหมาะสมสำหรับสินทรัพย์ที่เลือก│
│    - Monte Carlo Bootstrapping (resample ทุก iteration) │
│    - Ledoit-Wolf Covariance บน GPU                      │
│    - Entropy Regularization: ป้องกันน้ำหนักกระจุกตัว   │
│    - Penalty: จำกัด max_weight = 10%                    │
│                                                         │
│ Fitness = Sharpe + λ × Entropy - Penalty               │
│ (λ = 0.05)                                              │
└─────────────────────────────────────────────────────────┘
```

### 9.3 การค้นพบหลัก 5 ข้อจาก Summary.ipynb

1. **Ledoit-Wolf บน GPU ช่วยได้จริง**: LW Diversification Selected ให้ผลดีที่สุดระยะยาว (Sharpe 1.1029) เพราะ Covariance Matrix ที่เสถียรกว่าทำให้คัดสินทรัพย์ได้แม่นยำขึ้น

2. **Cluster-Based Methods ลด Volatility**: วิธีที่ใช้ HRP Clustering บังคับให้ Vol อยู่ในช่วง 13-14% ต่อปี (ต่ำกว่า SPY ที่ 15.42%) แต่แลกด้วยผลตอบแทนที่ต่ำลง

3. **2D-ACO เรียนรู้ Synergy ได้**: 2D-ACO มี Avg Correlation ต่ำที่สุดในกลุ่ม Non-Cluster (0.2760) แสดงว่าการเรียนรู้คู่หุ้น (Pheromone Matrix 2D) ช่วยหาสินทรัพย์ที่ "เข้ากัน" ได้จริง

4. **ความซับซ้อนไม่ได้แปลว่าดีกว่าเสมอ**: Co-Evolutionary ACO+EBGWO ที่ซับซ้อนที่สุดกลับให้ผลสะสมต่ำกว่า SPY ในช่วงยาว (188% vs 196%) ขณะที่ Simple Diversification Score ให้ผล 706%

5. **ปี 2025 เป็นบทเรียนสำคัญ**: ทุกกลยุทธ์แพ้ SPY ในปี 2025 เพราะตลาดสหรัฐฯ มีช่วงขาขึ้นแรงจากหุ้น Mega-Cap ที่ไม่ได้อยู่ในพอร์ต อย่างไรก็ตาม กลยุทธ์ที่ใช้ Cluster ช่วยจำกัด Drawdown ให้ต่ำกว่า SPY ได้ (LW Sharpe Cluster: -15.06% vs SPY -19.21%)
