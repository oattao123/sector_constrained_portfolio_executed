365d

Drop assets with consecutive missing values longer than 365 days.

Return transform

Weight Optimization and Objective

Representation

  • ACO selection: integer / discrete path encoding.
  • PSO, EBGWO, SI/DE-style methods: float weight vectors.
  • Current optimization is long-only.

Objective

Maximize Sharpe Ratio with entropy reward and concentration / constraint penalties.

Fitness uses Ledoit-Wolf volatility estimates and annualized return assumptions.

PSO

Particles search weight space using personal and global best portfolios.

ACO

Pheromone trails and Sharpe heuristics bias asset paths.

EBGWO

Wolf population follows leading solutions while preserving exploration.

Implemented latest runs: PSO and ACO+EBGWO6
